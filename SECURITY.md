# Security

AI SOC Analyst v0.1 is a single-user localhost lab using synthetic records. It has no production authentication, authorization, tenant isolation, ingestion pipeline, or automatic response capability. Keep it on loopback.

Do not put actual credentials, customer data, or production telemetry in issues, test fixtures, or screenshots. `.env`, SQLite files, virtual environments, and private key extensions are excluded from Git. No provider keys are required.

For a suspected vulnerability, use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the repository owner privately through their GitHub profile; avoid publishing exploit details or secrets in a public issue.
